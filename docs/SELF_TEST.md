# 单骑 · 汉字塔防 —— 30 条功能自测清单（Day 29 交付版）

> 测试环境：Edge（file:// 直开），Windows 10/11，1920×1080。
> 结果：**30 / 30 通过**；连续 3 局无崩溃；Console 无红字。

## 棋盘与对局（1–6）

- [x] 1. 8×10 棋盘、上下两半 180° 对称、窗口内不变形
- [x] 2. 每半 16 格 U 形路径，敌兵严格沿路径走、不穿墙
- [x] 3. 白格可放兵；深绿格需用铲子卡挖开变白格
- [x] 4. 双方同一波次、同一种怪、同血量
- [x] 5. 阿斗 3 颗心（6 漏点）显示正确；漏怪碎心；归零判负
- [x] 6. 暂停 / 继续正常；切后台回来不跳帧

## 经济与征兵（7–12）

- [x] 7. 击杀 +1 馒头；漏怪 +5（有飘字）
- [x] 8. 每波清完有奖励（6 + 2 × 波数）
- [x] 9. 征兵 5 张卡、整席替换、旧卡消失
- [x] 10. 征兵费用递增（10, 12, 14…），按钮显示下次价格
- [x] 11. 馒头不够时按钮置灰 / 提示
- [x] 12. 铲子以卡片形式占备战席 1 格（约 55% 概率换卡）；拖到深绿格挖开，拖别处归位不消耗

## 兵种与合成（13–17）

- [x] 13. 刀 / 枪 / 弓 / 骑行为明显不同（近战 / 穿透 / 远程 / 溅射），射程覆盖全白格
- [x] 14. 自动索敌，优先打最靠近阿斗的敌人
- [x] 15. 同种同级合成升级，属性按公式上涨
- [x] 16. 5 级封顶，满级不能再合
- [x] 17. 四兵种攻击有字形变（刀抡 / 枪刺 / 弓射 / 骑扫）+ 命中反馈

## 武将（18–22）

- [x] 18. 金色单字能抽、能放场上休眠
- [x] 19. 姓 + 名按顺序相邻 → 觉醒；顺序错 / 不搭配有提示
- [x] 20. 6 个武将（3 金 3 紫），金 / 紫边框可区分；金将 3 个技能会自动释放
- [x] 21. 武将占 2 格、拖任意一格可拆开、重聚再觉醒、重组后技能 CD 回满
- [x] 22. 兵可拖回备战席（保留兵种和等级），席满则归位

## AI 与局外（23–28）

- [x] 23. AI 会征兵、放兵、合成、挖格、用武将
- [x] 24. 三档难度体感不同（digCap 1 / 4 / 6 + 决策间隔 + 失误率）
- [x] 25. 无限波：谁先漏光谁输；无 12 波上限；6 分钟后加时赛
- [x] 26. 结算面板显示胜负 / 心数 / 波数；再来一局 / 返回首页正常
- [x] 27. 军衔 / 星星能升能降，刷新后还在
- [x] 28. 存档带版本号；手动写坏存档刷新不白屏（回退新档）

## 画风与性能（29–30）

- [x] 29. 纸底 + 草地石砖 + 墨字 + 朱砂点缀；品质边框 / 等级角标 / 敌方血条正常；开场「斗」字动画可跳过
- [x] 30. 60fps 稳定、粒子上限 60–80、无内存泄漏、Console 无红
