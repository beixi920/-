# 单骑 · 汉字塔防

> 30 天学习阶段作品 · 玩法致敬《赵云与阿斗》（蜜獾工坊）
>
> 纯静态、零依赖的汉字塔防：上下分屏与 AI 对战，同一波敌人同时进攻双方，先漏光阿斗的 3 颗心的一方输。

---

## 一、怎么运行

1. 双击项目根目录的 `index.html`（推荐 Edge / Chrome）；
2. **不需要 Node、Python、本地服务器或任何安装**，`file://` 直接运行；
3. 存档写在浏览器 `localStorage` 里，换浏览器不互通；清空浏览器数据会丢档。

---

## 二、玩法

- **棋盘**：8 列 × 10 行，上下两半（180° 对称）；每半 16 格 U 形路径；白格可放置，深绿格需要用铲子卡挖开；
- **经济**：开局 0 兵、20 馒头；击杀 +1 馒头，漏怪 +5；每波清完有奖励（6 + 2 × 波数）；
- **征兵**：一次 5 张卡、整席替换，费用 10 → 12 → 14 … 递增；每张卡 65% 兵种 / 35% 武将单字，另有 35% 概率把其中 1 张换成铲子卡；
- **合成**：同兵种同等级拖到一起合成升级，最高 5 级；
- **武将**：金色单字可放场上休眠；姓在左、名在右相邻即觉醒；拖动武将任意一格可拆开，重新摆成正确顺序会再次觉醒；武将占 2 格，金 / 紫品质、金将带技能（自动释放）；
- **对局**：无限波，每 6 波出现 BOSS「将」；6 分钟后进入加时赛（每波额外 +5% 血量）；谁先漏光 6 个漏点（3 颗心）谁输；
- **难度**：简单 / 普通 / 困难，主要差别是 AI 的挖格能力 + 决策间隔 + 失误率。

## 三、操作

- 点「征兵」抽卡；
- 拖卡到白格 → 放兵；拖同种同级到已有兵上 → 合成；
- 拖到已占用格 → **交换位置**（兵种 / 等级都不变；金色描边 = 可交换，朱砂描边 = 可放置）；备战席卡拖到已占格时，卡上场、原单位回到这张卡原来的席位上（保留兵种与等级）；
- **武将参与交换会解体**：拖武将任意一格到别的单位上、或把单位 / 卡拖到武将某一格，都会先拆成两张单字再换位，摆回「姓左名右相邻」自动重组（技能 CD 回满）；武将↔武将不直接交换，会提示先拆开；
- 拖铲子卡到深绿格 → 挖开变白格；拖到别处 → 归位不消耗；
- 拖兵到备战席 → 收回（保留兵种和等级）；席满则归位；
- 拖武将任意一格 → 拆开；两字重新姓左名右相邻 → 自动重新觉醒；
- 点「开始游戏」后播放开场动画，点击任意处可跳过。

## 四、技术栈

- 纯静态：`index.html` + `styles*.css` + 原生 JS（经典 `<script>` + IIFE 挂 `globalThis.Game`）；
- 渲染：Canvas 2D（棋盘 / 单位 / 特效）+ DOM（HUD / 按钮 / 备战席）；
- 数据驱动：数值全部在 `data/balance.js`，棋盘布局在 `data/board_map.js`，代码里不写死；
- 固定 60Hz 逻辑步长（accumulator + `requestAnimationFrame`），逻辑层（state / combat / waves / ai / skill / hero / recruit / meta / save）不碰 DOM，可在无头模拟中复用；
- 存档：`localStorage`，带 `version` + `migrate()`，坏档自动回退新档；
- 零依赖、零网络请求、无外部图片/字体/音频文件；所有画面程序化绘制。

  skill.js              武将技能与敌人状态（眩晕/灼烧/抗性）
  hero.js               武将拼字、拆开、重组
  recruit.js            征兵 5 张卡（兵种/单字/铲子卡）
  drag.js               拖拽：放置/合成/交换/收兵/挖格/拆武将
  ai.js                 AI 对手：征兵、放兵、合成、挖格、拼将
  meta.js               金币、军衔、武器背包

  render.js             棋盘与单位绘制
  board-art.js          棋盘地形静态层（只生成一次）
  render-fx.js / weapon-fx.js / weapon-art.js / qiang-fx.js   攻击形变与特效
  bench-art.js          备战席卡面（含铲子图标）
  intro.js              开场「斗」字动画
  art.js                画风参数与缓存
  rng.js                可复现随机数
  ui.js                 HUD、按钮、结算面板

  GDD.md                玩法规格（最终版）
  ART.md                水墨/卡通画风指南

## 六、已实现 / 简化说明

**已实现**

- 8×10 双半场棋盘、16 格 U 形路径、无限波与加时赛；
- 刀 / 枪 / 弓 / 骑四种行为 + 攻击时「字变武器」动画；
- 6 个武将（3 金 3 紫）：品质边框、占 2 格、拼字觉醒、拆开重组、金将技能；
- 铲子卡（占备战席）、深绿格开挖、兵可收回备战席；
- 三档 AI、军衔 / 金币 / 武器简版 / 存档；
- 开场「斗」字动画、水墨卡通画风、60fps 静态层缓存；
- `test/sim.html` 无头模拟调平衡（600 局 / 档无 NaN）。

**简化（放 v1.1）**

- 武将 6 个（原版 12+）、武器 8 件、地图 1 张、波次无限但地图单一；
- 未做：武将光环、农 / 宝箱、商店、每日重置、排行榜、广告、真人 PvP、音效。
